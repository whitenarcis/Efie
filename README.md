# Эфи

Асинхронный AI-компаньон для Telegram (userbot на Pyrogram) — архитектурный
гибрид двух референсов: рабочих проактивных механик текущей реализации Эфи
(спонтанные пинги, дневник, гуманизация вывода) и архитектурного каркаса
Kuni (единая очередь событий с закреплением чата за воркером, изоляция
инструментов, роль-based роутинг LLM).

Главный ориентир проекта: сделать диалог и поведение неотличимыми от
реального человека — не за счёт одного трюка, а за счёт архитектуры в целом
(единая точка обработки для всех проактивных и реактивных событий, слой
гуманизации вывода как первоклассная подсистема, а не приписка сбоку).

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

cp behavior.toml.example behavior.toml
# заполнить telegram.api_id/api_hash/owner_id и llm_roles.*.primary.api_key

python scripts/run.py --log-level INFO
```

Конфигурация читается в порядке приоритета: явные значения при создании
`Settings()` → переменные окружения (`EFI_*`, см. `efi/config/schema.py`) →
`behavior.toml` → значения по умолчанию. Секреты (API-ключи, `api_hash`)
никогда не коммитятся — используйте `.env` или переменные окружения в
продакшене.

## Архитектура

```
efi/
├── app.py              # точка сборки: связывает все подсистемы, graceful shutdown
├── config/schema.py     # типизированный конфиг (pydantic-settings)
├── llm/                 # LLMProvider(ABC), OpenAI-совместимый провайдер, LLMRouter (роли MAIN/FAST/VISION)
├── memory/               # Diary (RAG), рабочая память, факты, консолидация
├── db/                   # aiosqlite: единый connection manager + миграции
├── notifications/        # NotificationManager (pinned workers) + Worker (tool-calling цикл)
├── tools/                 # инструменты LLM: один класс — один файл
├── telegram/               # Pyrogram-обёртка, обработчики событий, обработка медиа
├── behavior/                # проактивность: планировщик, спонтанные пинги, монитор тишины
├── humanizer/                 # опечатки, задержка набора, anti-repeat, разбивка на сообщения
├── security/                   # санитайзинг входа, Lockdown-режимы доступа
└── prompts/                     # сборка системного промпта: личность + время + память + безопасность
```

## Известные незакрытые места

- **Дашборд** (`efi/dashboard/`) не реализован — задел под метрики есть
  (`efi/llm/measurable.py`), но подсистема визуализации отсутствует.
- **`efi/behavior/curiosity.py`, `trends.py`, `channel_blog.py`** — не реализованы.
- **`GenerateImageTool`/`GenerateVoiceTool`** реализованы, но не подключены в
  `app.py` — нужны поля конфигурации для Pollinations/ElevenLabs, которых
  пока нет в `Settings`.
- **Тесты** — не реализованы.
- Действия модерации (`group_admin.py`: бан/удаление) сознательно не
  реализованы — такие инструменты требуют отдельного обсуждения гарантий
  безопасности перед тем, как давать их модели.
